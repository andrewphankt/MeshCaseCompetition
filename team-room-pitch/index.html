No new IDE. No new model bill. A connector, a room, one branch.

[Speaker: Andrew. Target: about 35 seconds. 5 clicks, one per step, then the tagline.] This is for the engineers in the room. Each teammate keeps their own agent on their own laptop. Mesh adds a small connector: three hooks the agent already supports (in Claude Code: UserPromptSubmit, PreToolUse on Edit and Write, and Stop; Codex and Gemini use their equivalents). Click 1, before each task: the hook pulls the team’s latest draft and hands the agent what teammates changed and any messages for it. Click 2, before each edit: it asks the room who is in that file. If another agent is, the edit is blocked and the agent asks its person: wait, or take another part. Click 3, after each turn: it saves to one shared branch called draft. If two agents changed the same lines, both versions are kept and the agent must combine them. Click 4: the draft is a live preview; only a person can Push it to main. Click 5: no new IDE, no new model bill. A connector, a room, one branch. Then: “Let’s see it live.” If asked how the room decides who’s in a file, or how merges work in detail: stay at this level until our provisional patent is filed. Partnership angle if asked: any agent with hooks can join a Mesh room, and the draft can preview or deploy anywhere, including Replit.

How Mesh makes money.

Our moat is convenience. Teams bring the agents they already use (Claude Code, Codex, Gemini CLI, Antigravity) into one room on one GitHub repo. No new tool to learn and no new AI to pay for. Mesh is the room between your agents.

Businesses
Team sales

Companies
Partnerships

  • Microsoft Teams and calendar: see inside Mesh when a teammate is at lunch or busy.
Students
Free for now
  • That’s our current mission: help students build with AI, together.

Paid
Add-ons
