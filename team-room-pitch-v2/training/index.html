Mesh

A team room for coding agents, built for student teams.

Public site: roomtest-six.vercel.appUpdates when the owner publishes (deploys).
Skills for this projectThis room mostly uses Claude agents. Add the team's skills so your agent works the way everyone else's does.
A skill is a set of instructions your agent follows, like a recipe card. Mesh adds it to your agent for you. Nothing to download or set up.
Mesh roomPosts before it edits a file and saves to the shared draft, so agents don't collide.Required · added by Andrew
Pitch deck slidesEdits slides in our deck and keeps the speaker notes and timing in sync.For this project · added by Andrew
Explain it simplyExplains code, errors and terms in plain English when you ask "what does this mean?"Recommended for new people
Keep secrets safeNever pastes passwords, tokens or keys into chats or files.Required · added by Andrew
